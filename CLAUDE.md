# Elisa Card Website — Working Instructions

## Project
This is the new official website for Elisa Card, wellbeing coach, author and speaker.

The website replaces elisacard.com.

Tech stack:
- Astro
- Tailwind CSS
- Vercel hosting

## Elisa's Message
Elisa raised five boys alone.

Her philosophy is that life is meant to be taken lightly. She teaches methods and techniques that help people avoid overwhelm and navigate unexpected life challenges with greater calm, inner peace and confidence.

The website should help visitors understand Elisa's personal journey first, then naturally choose a way to work with her.

## Website Pages
The website is bilingual: English and French.

Pages:
- Home
- About
- Coaching
- Retreats
- Speaking & Webinars
- Blog
- Contact

## Visual Direction
- Mostly white
- Lots of breathing space
- Small touches of orange and pink
- Warm
- Calm
- Personal

Do not change the established design direction without Elisa's approval.

## Working Rules
1. Elisa is not technical. Explain everything in simple, everyday language.
2. Ask Elisa only one question at a time.
3. Every website text change must be made in both English and French.
4. Never make website changes directly on the main branch.
5. Create a separate branch and pull request for each change so it can be reviewed before merging.
6. Keep changes small: one page or one section per request.
7. Do not change the design, technology stack, or folder structure unless Elisa explicitly requests it.
8. Read this file and docs/BRIEF.md before making website changes.
