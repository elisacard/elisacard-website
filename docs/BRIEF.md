# Brief — Elisa Card website

Decisions confirmed by Elisa. Update this file when a new decision is made.

## Goal
A working bilingual website (English and French) replacing elisacard.com by 31 October 2026.

## Visitor journey
1. Understand Elisa's personal journey first.
2. Then choose a way to work with her: Coaching, Retreats, Speaking & Webinars.

## Languages
- English is the main version, at elisacard.com/ (decided 5 Oct 2026).
- French is at elisacard.com/fr/ with the same page names.
- A one-tap switch (EN / FR) on every page leads to the same page in the other language.

## Where things are
- All texts, both languages side by side: `src/i18n/texts.ts`. Placeholders are marked `TODO`.
- Colours: `src/styles/global.css` (white base, orange and pink touches).
- Page designs: `src/views/`. Page addresses: `src/pages/` (English) and `src/pages/fr/` (French).

## Look
Mostly white, lots of space, small touches of orange and pink. Warm, calm, personal.
Fonts: Lora for titles, Nunito Sans for text.
